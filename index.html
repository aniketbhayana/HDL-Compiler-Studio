Review 1: Lexical Specification (hdl_lexer.l)

The lexical analyzer is constructed using Flex and compiled with GCC. It breaks raw HDL code into atomic tokens based on deterministic finite automaton (DFA) state transitions.

Token Classes & Regular Expressions

  • Keywords: "input" | "output" | "wire" | "reg" — Identifies hardware signal classes.
  • Gate Operators: "and" | "or" | "not" — Primitive logic gates.
  • Identifiers: [a-zA-Z_][a-zA-Z0-9_]* — Signal and port identifiers.
  • Numbers: [0-9]+ — Constants and bit widths.
  • Punctuation & Delimiters: ; , ( ) — Statement terminators and argument separators.
  • Operators: = — Signal assignment.

Symbol Table Logic

When any declaration keyword (input, output, wire, reg) is encountered, the lexer enters an active declaration state (in_declaration = 1). All subsequent identifiers are logged in the Symbol Table with their category until the next semicolon (;) resets the state.
